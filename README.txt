AF1 CUSTOMS WEBSITE

1. Open index.html in a browser to preview the site.
2. The photos are in the images folder.
3. Before publishing, edit index.html:
   - Change AF1 / CUSTOMS to your actual brand name.
   - Add your Instagram/email to the commission section.
   - Add your sponsor name/logo when you have it.
4. The commission form currently copies the request text so you can paste it into DMs/email.
5. The site includes a simple Nike non-affiliation disclaimer.

For publishing, upload index.html + the images folder to a static web host.
